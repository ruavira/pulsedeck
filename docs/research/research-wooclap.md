# Wooclap Research Report (July 2026)

Brussels-based (founded 2015), 50M+ learners, ~4.4/5 on G2 (81 reviews). Positioned for higher-ed lectures, conferences, corporate training.

## 1. Feature inventory
- **20+ activity types**: MCQ, poll, word cloud, open question, brainstorming (idea board), rating/scale, prioritization/ranking, sorting, matching, drag-drop, fill-in-blanks, guess-a-number, find/label-on-image, video/audio questions, math (LaTeX formula editor), Script Concordance Tests (SCT — unique, medical-ed oriented), Q&A "Message Wall" with upvoting.
- **Engagement**: Competition mode (leaderboard), team mode ("Answer as a group"), timers, Spin the Wheel, anonymous mode, "I'm confused" signal button.
- **Presenting**: import slides and interleave questions; presenter view; self-paced (async) questionnaires; attendance tracking; per-participant analytics.
- **Moderation**: moderator interface for Message Wall/open answers — Pro+ only. **Branding/themes**: custom branding Pro+; users complain customization is limited.

## 2. Pricing & limits (2025–2026)
- **Hard cap all plans: 1,000 real-time participants/event**; beyond that display of answers can lag; word clouds have display limits at scale. Larger events = contact sales (Corporate).
- **Starter (free)**: changed from old "2 questions per event, unlimited events" to **5 "active" questions per rolling 30 days** (a question counts as active once 3+ unique participants answer it in one event). Up to 1,000 participants, all question types, PPT/Slides/Teams/Zoom integrations. Can view but **not export** results.
- **Basic** (edu ~$7.99–8/presenter/mo annual [unverified, third-party]): unlimited questions, PDF/Excel export, self-paced sessions, question import.
- **Pro** (~$14.99/presenter/mo [unverified]): + AI agents, team collaboration, custom branding, moderator mode, SMS participation.
- **Campus/Corporate** (custom, min 6 licenses): LMS/LTI, SSO (SAML/CAS), admin analytics dashboard, dedicated support. Free for K-12 teachers in France & Belgium. Per-presenter licensing — cost stacks across departments ("It is expensive" is a recurring review theme).

## 3. AI features
"Wooclap AI" / Question Builder (Pro+): generates 7 question types (MCQ, open, poll, fill-in-blanks, matching, brainstorming, math/LaTeX) from a topic prompt, pasted text, URL, documents (PDF/PPT/Pages/ODF, ≤200MB), or audio/video (≤250MB, audio only). No AI deck generation or answer summarization documented. Quality: reviewers describe output as "a draft to refine, not a finished lesson" — good prep accelerator. Wooclap states no model training on user data. Sister product **Wooflash** (AI + spaced-repetition microlearning) is a separate app.

## 4. Import/export
- **Import**: PowerPoint, PDF, Keynote uploads — **slides convert to static images; animations lost**. Google Slides via link. Alternatively keep animations by embedding Wooclap into PPT/Google Slides via add-ins. Question import (Basic+), incl. Excel.
- **Export**: results in **Excel, PDF, CSV** (Basic+ only); views: full presentation, per-question, per-participant, grid; Message Wall separately to Excel. No native deck export to PPT documented [unverified].

## 5. Join flow
Browser-based, **no app, no participant account**: wooclap.com + event code, QR code on screen, or direct link. **SMS/text answering** (Pro+, live only, disabled by default) via numbers in US/CA (toll-free)/UK/FR/BE/DE/NL/ES/AU — notable offline/no-wifi fallback. Works on any smartphone/laptop; real-time display generally fast under 1,000 users.

## 6. UX/UI sentiment
**Praise**: very easy for beginners; question variety "keeps students alert"; increases engagement; responsive support team; anonymous mode; STEM formula support. **Complaints**: no mobile app for presenter/moderation from phone; mobile participant text-sizing/navigation issues; occasional disconnections/freezes mid-session; limited theming; weak async/self-paced controls; no long-term learner progression tracking; free tier now too restrictive (5 active questions/month).

## 7. Reliability at scale
1,000-participant ceiling regardless of plan; latency and word-cloud rendering degrade near/above it. Wifi dependency flagged in 100+ student rooms; SMS is the mitigation. No major publicized outage at large events found [unverified].

## 8. Integrations & API
PowerPoint add-in, Google Slides add-in, Teams and Zoom embedding, LMS via **LTI 1.3** (Moodle, Canvas, Blackboard, Brightspace) with grade/attendance/participation sync (Campus tier). **No public developer API** (API Tracker lists none; integration is LTI-based) [unverified].

## 9. Strengths / weaknesses / 2025–26 developments
**Strengths**: pedagogical depth (SCT, LaTeX, 20+ types), frictionless join + SMS fallback, strong LMS/PPT integration, EU/GDPR posture. **Weaknesses**: 1,000-participant hard cap, per-presenter pricing, static slide import, no mobile presenter app, tightened free tier, no public API. **Recent**: **$29M (€25M) round led by Impact Expansion (announced ~April–Sept 2025)** for North America expansion + AI; **major UI overhaul Sept 2, 2025** ("Votes"→"Live Session", consolidated settings, Share Event); expanded AI agents on Pro; Wooflash push.
