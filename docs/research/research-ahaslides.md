# AhaSlides — Research Brief (as of July 2026)

## 1. Feature inventory
- **Activity types:** multiple-choice polls, image-choice polls, word clouds, rating scales, ranking polls, open-ended/brainstorm (Idea Board with upvoting), live Q&A, Pin-on-Image, Spinner Wheel, and quiz formats: Pick Answer, Match Pairs, Correct Order, Categorise, Short Answer/Type Answer. Gamification: leaderboards, Team Play, self-paced mode (homework/spaced repetition), emoji audience feedback.
- **Presenting:** content slides (text/image/video/YouTube/website embeds), thousands of templates (~300 added Jan 2025 across 7 languages), presenter remote-control from phone, presenter notes, audience-side language support (30+ langs; Swedish added Jan 2025; PT/PL/NL/LV added Aug 2025).
- **Moderation/branding:** Q&A moderation queue (paid), anonymity toggle, profanity filter, submission controls, custom backgrounds/colors (Essential+), custom branding + custom join code + audience authentication (Pro), SSO (Enterprise).

## 2. Pricing & limits (post-Sept 2024 restructure; Plus tier discontinued)
| Plan | Price | Live participant cap | Key limits |
|---|---|---|---|
| Free | $0 | 50 | 5 quiz + 3 poll questions/deck; unlimited events/month; 5 AI queries/mo |
| Essential | $7.95/mo | 100 | unlimited questions; Excel export; basic analytics; 20 AI queries/mo |
| Pro | $15.95/mo | 2,500 (some listings say 10,000 — [unverified]) | branding, custom code, audience auth, participant-level reports, unlimited AI |
| Enterprise | custom | up to 100,000 | SSO, premium support |
| Edu Small/Medium/Large | $2.95 / $5.45 / $7.65/mo (annual) | 50 / 100 / 200 | Medium adds analytics/shuffle; Large adds Q&A moderation, auth, export |
Annual billing saves "up to 67%." Over-cap behavior: presentation continues; excess participants simply can't join.

## 3. AI features
AI Presentation Maker (topic → full interactive deck with polls/quizzes in <1 min), AI quiz/question generation from uploaded PDF/PPT, AI-generated Match Pairs (Jan 2025), AI icebreaker/opener generator, "AhaSlides GPT" (beta), and an **MCP tool/server** for AI-agent access to presentations (2025-26 — notable, competitors lack this). Quotas: 5/20/unlimited queries (Free/Essential/Pro). Independent 60-day test (fahimai.com): AI decks "usable" from a single prompt but generic; design customization limited.

## 4. Import/export
Import: PPT/PPTX and PDF (slides render as static images); Google Slides via add-on (Jan 2025). Export: results to Excel/CSV (two report versions as of Aug 2025 — v1 instant, v4 pivot-ready with ~10-min refresh, request-only), slides to PDF/JPG, reports & analytics dashboards (Edu Medium+/Essential+). Complaint: exports lack visual polish.

## 5. Join flow
Browser-based, no app, no audience account: ahaslides.com/CODE URL, code entry at audience.ahaslides.com, or per-deck permanent QR code (unchanged even if code edited). Custom short codes on Pro. Works on any phone/tablet/PC browser. PowerPoint add-in (Aug 2025) now uses one QR for the whole deck. Latency: near-real-time; reviewers report lag on weak venue Wi-Fi and connection drops needing reload at ~40+ simultaneous joins [single-reviewer observation].

## 6. UX/UI reputation
G2 4.7/5 (~317-326 reviews, G2 Best Software 2026 badge); Capterra 4.6/5 (~61 reviews). Praised: ease of use, price vs Mentimeter/Slido/Kahoot, generous free tier, responsive support (even off-hours). Complaints: limited design/customization (42 of 317 G2 reviews), **no undo** in editor, clunky text alignment, browser inconsistencies (worst on Safari/Mac), free-tier question caps frustrate educators, "second-screen" friction inherent to category.

## 7. Reliability at scale
Marketed to 100k (Enterprise); users report handling "hundreds" fine. Fully internet-dependent — **no offline mode**; Jan 2025 added auto-reconnect UI ("Reconnecting…" status + audience notification), acknowledging drop issues. No documented large-event outages found [unverified absence]. Third-party critiques: no preview/test mode, weaker moderation at scale.

## 8. Integrations & API
PowerPoint add-in (Microsoft AppSource; embed interactions inline, revamped Aug 2025), Google Slides add-on (Jan 2025), Zoom, Microsoft Teams (incl. export-to-Teams), Webex, RingCentral Events (Hopin), ChatGPT/AhaSlides GPT, MCP server. Integrations free on all plans. **No public REST API, no Zapier, no LMS (Canvas/Moodle) integration found** — a gap vs Poll Everywhere/Slido.

## 9. Strengths / weaknesses / 2025-26 developments
- **Strengths:** cheapest credible Mentimeter alternative; widest quiz-type variety; app-less join; unlimited free events; Edu plans from $2.95; MCP/AI-agent angle.
- **Weaknesses:** design ceiling, no undo, no offline, no API/LMS hooks, Pro cap ambiguity (2,500 vs 10,000), analytics thin below Pro.
- **2025-26:** Google Slides add-on (Jan 2025), AI Match Pairs + reconnect UI (Jan 2025), single-QR PowerPoint add-in + v4 reporting (Aug 2025), MCP tool, product updates relocated off blog (2026).
